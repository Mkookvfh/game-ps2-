
# PROJECT WESTERN

An original Western open-world action-adventure game for Android.

## Technology
- Engine: Unity 6.3 LTS
- Render Pipeline: Universal Render Pipeline (URP)
- Platform: Android
- Input: Touch Controls
- Language: C#

## Current Milestone: M0
Foundation setup:
- Mobile player input
- Third-person character controller
- Sprint hold button
- Android build workflow

## Project Structure

- Assets/Scripts/Player
- Assets/Scripts/UI
- Packages
- ProjectSettings

## Development Rules
- Android is the target platform.
- Use original characters, story, and assets.
- Keep existing PS2 project files unchanged.
- Test all systems before release.

## Build Status
Initial project setup. Android build prerequisites
and Unity scene configuration are still pending.
